# Hummels-Tribe-Trader

Ein eigenständiger Handelsrechner für ARK: Survival Ascended.

## Über das Projekt

Hummels-Tribe-Trader ist ein unabhängig entwickelter Rechner zur Berechnung von Handelspreisen für Kreaturen und Gegenstände, aktuell nur für den RuhrpottSurvivors Cluster.

Das Projekt wird von Hümmelchen entwickelt und vom Tribe OpferKlopfer zur freiwilligen Nutzung zur Verfügung gestellt.

## Status

Das Projekt befindet sich in der Weiterentwicklung.
